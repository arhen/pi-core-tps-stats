# @arhen/pi-tps-stats

[![npm version](https://img.shields.io/npm/v/@arhen%2Fpi-tps-stats?color=cb3837&logo=npm)](https://www.npmjs.com/package/@arhen/pi-tps-stats)
[![license](https://img.shields.io/badge/license-MIT-blue.svg)](./LICENSE)

Live token-per-second stats for the active model. Status bar shows median streaming t/s + average TTFT; `/tps-stats` shows full stats (samples, avg/median/min/max, effective t/s, TTFT). Stats reset on model change.

## Install

```sh
pi install npm:@arhen/pi-tps-stats
```
